How to use Settings

Company legal name, TRN, VAT status, and fiscal year month set karo. VAT registered company layi TRN zaroor fill karo.

How to use Chart

First time “Default Chart” click karo. Fer sirf company-specific account add/edit karo. Posted journals wale accounts disable karo, delete nahi.

How to use Journals

Debit total and Credit total same hone chahide. Pehle Save Draft, check karo, fer Post Journal. Galti hove taan Reverse use karo.

How to use Reports

Report type and date range select karo, then Preview. Monthly closing layi Trial Balance, Profit & Loss, Balance Sheet, VAT Summary check karo.
